# VEIL — Binary Reflected Gray Code Explorer

**The most elegant way to traverse binary space.**

A luxurious, high-fidelity digital artifact demonstrating the beauty and utility of **Binary Reflected Gray Code** — the encoding that changes only one bit at a time.

## Why This Matters

In hardware, signal integrity, rotary encoders, Karnaugh maps, and error-resistant systems, Gray code is king. This experience honors that precision with obsessive attention to detail.

## Features

- Real-time encode/decode with buttery smooth bit animations
- Live 8-bit visualizer with physics-like transitions
- Complete 5-bit codex table
- Production-grade implementations in Python, JavaScript, and Java
- Immersive particle canvas background
- GSAP-powered micro-interactions
- Zero-dependency core logic

## Tests Passed

- `gray(true, 177)` → `233`
- `gray(true, 425)` → `381`
- `gray(true, 870)` → `725`
- All decode inverses match

I built this because most technical demos feel sterile. VEIL treats code like craftsmanship — gold accents, deep voids, and deliberate motion.

Made with deep respect for low-level computing elegance.
